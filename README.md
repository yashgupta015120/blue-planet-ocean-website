# BLUE / PLANET — Ocean Life & Marine Conservation

A responsive educational website about ocean biodiversity, marine ecosystems, threatened species, and practical conservation initiatives.

## Files

- `index.html` — page structure and content
- `style.css` — responsive deep-ocean visual design, cards, scroll effects, and mobile layouts
- `script.js` — mobile navigation, scroll progress/reveals, fallback-managed marine photography, ecosystem selector, checklist progress, and feedback form validation

## Run locally

Keep all three files in the same folder and open `index.html` in a modern browser. Internet access is recommended because the site uses Google Fonts and photographs hosted by Unsplash.

## Features

- Cinematic marine landing page with layered typography and scroll depth
- Marine species feature cards and ocean facts
- Coral reef, mangrove, open-ocean, and polar-sea interactive habitat selector
- Habitat images switch with the selected tab and automatically try alternate image URLs if one fails
- Marine conservation initiatives and an interactive personal-action checklist
- Responsive mobile navigation and scroll-reveal effects
- Email validation and on-page feedback confirmation

## Feedback form note

The form is a front-end demonstration only. It validates the email address and displays confirmation in the browser; it does not send or store information on a server.
