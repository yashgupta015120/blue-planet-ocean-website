## 🐋 About the project

**BLUE / PLANET** is an ocean-life and marine-conservation website built with **HTML, CSS, and vanilla JavaScript**. Its cinematic, deep-blue visual style pairs oversized typography, layered imagery, and scroll reveals with approachable information about the species and ecosystems that make our oceans extraordinary.

The goal is simple: help visitors discover the ocean, understand the pressures marine life faces, and find realistic ways to make a difference.

> *One blue planet. Countless lives. A future worth protecting.*

## ✨ Features

| Experience | What it does |
|---|---|
| 🌐 **Immersive hero** | Large editorial typography, ocean imagery, and a cinematic first impression. |
| 🐢 **Marine biodiversity** | Introduces sea turtles, blue whales, coral reefs, and the importance of healthy seas. |
| 🪸 **Interactive habitat explorer** | Switch between **coral reefs, mangroves, the open ocean, and polar seas** to explore their roles and conservation needs. |
| 🖼️ **Smart image fallbacks** | Habitat photography changes with the selected ecosystem and tries alternate image URLs if one fails. |
| 🌱 **Conservation initiatives** | Covers habitat protection, reducing plastic waste, thoughtful seafood choices, and respectful wildlife viewing. |
| ✅ **Personal action checklist** | Tick off simple conservation actions and see your progress update. |
| 🎞️ **Scroll effects** | Reveal animations and a reading-progress indicator add movement as visitors explore the page. |
| 📱 **Responsive navigation** | Layout and navigation adapt for desktop, tablet, and mobile screens. |
| 💌 **Feedback form** | Validates the email field and displays an on-page submission confirmation. |

## 🌊 Explore the blue world

- **Coral reefs** — living habitats that provide shelter for diverse marine communities.
- **Mangrove forests** — coastal nurseries that support wildlife and help buffer shorelines.
- **The open ocean** — an immense environment connecting life across the planet.
- **Polar seas** — cold-water ecosystems where marine food webs depend on changing conditions.

Each habitat has a dedicated image and information about why it matters and how people can help protect it.

## 🧰 Built with

- **HTML5** for meaningful page structure
- **CSS3** for layout, responsive styling, transitions, and visual effects
- **Vanilla JavaScript** for habitat switching, navigation, scroll interactions, action tracking, and form validation
- **Unsplash-hosted photography** and **Google Fonts** for visual content and typography

> No TypeScript, framework, package installation, or build step is required.

## 🚀 Get started

### Option 1 — Open it directly

1. Download or clone this project.
2. Keep `index.html`, `style.css`, and `script.js` in the same folder.
3. Open `index.html` in a modern browser.
4. For the online photographs, fonts, and animated typing heading in this README, use an internet connection.

### Option 2 — Run a local server

If you use Visual Studio Code, open the project folder and launch `index.html` with the **Live Server** extension. You can also start any simple static web server from the project directory.

## 💌 About the feedback form

The form is currently a **front-end demonstration**: it validates the email address and displays a confirmation message in the browser. It does **not** send emails or save submissions to a database. To collect real feedback, connect the form to a secure backend or a trusted form service and include an appropriate privacy notice.
